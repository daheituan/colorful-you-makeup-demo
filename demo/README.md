# Demo 演示素材

本目录用于放置演示视频与截图。

当前项目交付包中已经包含 `colorful-you-demo.mp4` 以及演示帧图片。由于本次使用的 GitHub 连接接口仅支持 UTF-8 文本文件写入，MP4 / PNG 等二进制素材没有通过接口上传到仓库。

正式提交时可将交付包中的：

- `demo/colorful-you-demo.mp4`
- `demo/frame1.png`
- `demo/frame2.png`
- `demo/frame3.png`

拖拽上传到本目录即可。代码运行不依赖这些文件。

## 推荐正式录屏流程

1. 打开 Demo 首页。
2. 上传一张正脸照片或点击“使用内置示例图”。
3. 切换 2–3 种妆容。
4. 调节妆容强度。
5. 拖动妆前 / 妆后分割线。
6. 点击“导出妆后图”。
