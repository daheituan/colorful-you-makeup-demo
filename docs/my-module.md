# 独立负责模块说明

## 我独立负责的模块：妆容预览与前后对比 Demo

我负责把原有偏实时摄像头的原型重构为一个更适合演示和验收的完整 MVP 流程，目标是让用户无需开启摄像头，也能通过一张照片快速判断不同妆容的大致适配效果。

### 1. 照片输入模块

- 实现浏览器本地图片上传。
- 使用 FileReader 读取图片，不将用户照片上传到服务器。
- 增加内置示例图，保证没有测试素材时也能直接演示。

### 2. 人脸关键点定位模块

- 接入 MediaPipe FaceMesh。
- 提取眼部、双颊、嘴唇等关键区域坐标。
- 将归一化坐标映射到 Canvas 像素空间。
- 增加识别失败时的基础位置估算，避免 Demo 因模型/CDN异常中断。

### 3. 妆效渲染模块

- 使用 Canvas 2D 绘制眼影、腮红、唇色。
- 通过径向渐变、模糊和透明度模拟自然融合效果。
- 支持 4 套妆容配色预设和强度调节。
- 用户切换风格时即时重绘结果。

### 4. 前后对比模块

- 使用两个 Canvas 分别保存原图与妆后图。
- 通过 CSS `clip-path` 和透明 range input 实现可拖动前后对比。
- 分割线位置与裁切区域同步，形成直观的“Before / After”效果。

### 5. 结果导出与演示稳定性

- 支持将妆后 Canvas 导出为 PNG。
- 设计状态提示：等待上传、正在识别、人脸定位成功、降级模式等。
- 页面做响应式适配，确保笔记本答辩屏幕上可正常展示。

## 技术栈

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas 2D
- MediaPipe FaceMesh

## 价值

这一模块完成了项目最关键的验证：用户是否愿意通过“自己的照片 + 妆容预览 + 前后对比”来降低试错成本。后续如果验证有效，可以继续升级为更高保真的实时 AR 试妆和个性化推荐。
